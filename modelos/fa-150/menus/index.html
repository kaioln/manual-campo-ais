Altera apresentação e alarmes locais; registrar o estado antes de mudar.

  • KEY BEEP
  • ALARM BUZZER

  • DISP SART TEST

Instalador autorizado; senha não divulgada

INITIAL SETTINGS

Altera identidade, dimensões/posição de antena, tipo, portas e canais. Exige autorização documentada.

  • SET MMSI
  • SET INT/EXT ANT POSN
  • SET SHIP TYPE
  • SET I/O PORT
  • SET LR CH
  • SET BLUE SIGN SW (Inland)

Fonte: OME-44310-M, PDF 84 e 86; IME-44310-P1, PDF 26-34

Operador/instalador conforme tarefa

CHANNEL SETTINGS

Configura canais, potência e área regional; alteração indevida afeta transmissão.

  • VIEW CHANNEL
  • EDIT CHANNEL → SELECT NO / TIME / FROM MMSI / TYPE / POWER / CH NO / MODE / ZONE / CH AREA

Fonte: OME-44310-M, PDF 85 e 87

Operador autorizado; itens restritos separados

DIAGNOSTICS

Testa unidades e consulta históricos; MEMORY CLEAR reinicia ou apaga estados específicos.

  • MONITOR TEST
  • TRANSPONDER TEST
  • PWR ON/OFF HISTORY
  • TX ON/OFF HISTORY
  • MEMORY CLEAR
  • ACTIVATE KEY
  • FOR SERVICE

Fonte: OME-44310-M, PDF 76-85

Regra antes de alterar

  1. Fotografe e transcreva o estado inicial.
  2. Confirme autorização para identidade, dimensões, posição de antena, portas e canais.
  3. Altere um parâmetro por vez, teste o efeito e registre.
  4. Se o resultado não for aprovado, restaure o valor documentado e escale a divergência.
