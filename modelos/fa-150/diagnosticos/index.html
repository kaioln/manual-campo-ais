Testes e históricos

MENU → DIAGNOSTICS → MONITOR TEST

Monitor test

Verifica: Números de boot/programa, ROM, SDRAM, porta, teclas, contraste, dimmer e LCD preto/branco.

Resultado: ROM/SDRAM: OK ou NG. PORT pode indicar NG sem o conector especial de teste.

Próxima ação: Se NG persistir após repetição, o manual orienta contatar o representante.

OME-44310-M, PDF 76-77, 3.4.1

MENU → DIAGNOSTICS → TRANSPONDER TEST → MEMORY TEST

Memory test do transponder

Verifica: Programa, MAIN ROM, MAIN RAM, SUB RAM e versões de hardware MAIN/MOT/TX.

Resultado: OK ou NG por memória.

Próxima ação: NG deve ser escalado ao representante.

OME-44310-M, PDF 78, 3.4.2

MENU → DIAGNOSTICS → TRANSPONDER TEST → GPS TEST

GPS test

Verifica: Programa e receptor GNSS interno.

Resultado: OK ou NG com motivo: backup, comunicação, parâmetros, ROM, RAM ou antena.

Próxima ação: Correlacionar com INTERNAL GPS e SENSOR STATUS antes de substituir componentes.

OME-44310-M, PDF 78, 3.4.2

MENU → DIAGNOSTICS → TRANSPONDER TEST → VHF COMM TEST

VHF communication test

Verifica: Comunicação com MMSI selecionado automaticamente a 15-25 NM ou inserido manualmente.

Resultado: OK ou NG; NG também pode ocorrer por obstrução, TX MALFUNCTION, teste no primeiro minuto ou área sem transmissão.

Próxima ação: Executar somente autorizado; não interpretar NG isoladamente como defeito do transponder.

OME-44310-M, PDF 79, 3.4.2

MENU → DIAGNOSTICS → PWR ON/OFF HISTORY

Power on/off history

Verifica: 30 eventos recentes de energização/desenergização.

Resultado: Intervalos menores que 15 minutos não aparecem.

Próxima ação: Preservar como evidência antes de qualquer limpeza.

OME-44310-M, PDF 80, 3.4.3

MENU → DIAGNOSTICS → TX ON/OFF HISTORY

TX on/off history

Verifica: 30 eventos recentes de transmissão ligada/desligada.

Resultado: Data e hora dos eventos.

Próxima ação: Comparar com alarmes, perda de energia e relatos do passadiço.

OME-44310-M, PDF 80, 3.4.4

Limitação do teste VHF

NG pode ocorrer por obstrução, TX MALFUNCTION, primeiro minuto após a partida ou região sem transmissão. Execute somente com autorização e não condene o transponder por esse resultado isolado.
